# Chanh's Personal Website

A modern, responsive personal website built with Vue.js and Vite. This portfolio showcases skills, education, and provides a way for visitors to get in touch.

## 🚀 Features

- **Modern Design**: Clean, professional layout with smooth animations
- **Responsive**: Fully responsive design that works on all devices
- **Fast Performance**: Built with Vite for lightning-fast development and optimized builds
- **Vue 3**: Uses the latest Vue.js features and best practices
- **Contact Form**: Interactive contact form for visitor inquiries
- **Skills Showcase**: Visual representation of technical and soft skills
- **Education Timeline**: Professional education history and achievements

## 🛠️ Tech Stack

- **Vue.js 3** - Progressive JavaScript framework
- **Vite** - Next generation frontend tooling
- **CSS3** - Modern styling with Grid and Flexbox
- **JavaScript ES6+** - Modern JavaScript features

## 📦 Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd chanhengWebsite
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 🎨 Customization

To customize this website for your own use:

1. **Personal Information**: Update the content in each component with your information
2. **Images**: Replace placeholder images with your photos and project screenshots
3. **Colors**: Modify the CSS custom properties to match your brand colors
4. **Content**: Update the text content, skills, and project information
5. **Contact Details**: Add your actual contact information and social media links
